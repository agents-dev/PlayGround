# 🪱 Worms Armageddon — Browser Clone

Turn-based artillery carnage in the browser. No dependencies, just open `index.html`.

## Play
- Open `index.html` (or serve this folder with any static server).
- Red vs Blue, 2–4 worms per team, destructible island, wind, drowning water.
- Move `A/D`, aim `W/S` or mouse, jump `J/Enter`, backflip `Backspace`, hold+release `Space` to fire, `1–6` weapons.

## Weapons
`🚀 Bazooka` (wind) · `💣 Grenade` (bounce, 3s fuse) · `🔫 Shotgun` (2 shots/turn) · `🧨 Dynamite` · `🏏 Bat` · `🌀 Teleport`

## Files
- `index.html` — UI shell + HUD
- `styles.css` — styling
- `game.js` — terrain destruction, physics, turns, particles, synthesized SFX
