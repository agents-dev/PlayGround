OpenAI-Hosted Sandboxes

An OpenAI-hosted sandbox gives your agent a Linux workspace with Python, Node.js, and command-line tools. OpenAI provisions and connects it; your app supplies the task and retrieves the results. Working directory: /workspace.

Official doc · Files & artifacts · Container pricing

How it works

  1. Configure: environment.type = "openai_hosted" + packages, setup commands, files, env, skills/plugins.
  2. Network: enabled (default) · disabled · restricted with 1–100 bare hostnames.
  3. Wait for connected: provisioning → connected (or failed with environment.error).
  4. Artifacts: files under /workspace/outputs are published as immutable artifacts at turn end.
  5. Lifetime: keep-alives sustain it; ~1h idle can delete it. Delete the session when done (retry 409).

import OpenAI from "openai";
const client = new OpenAI(); // OPENAI_API_KEY stays in your app terminal, never in the sandbox
const stream = await client.beta.agents.sessions.create({
  agent: { model: "gpt-6-astra" },
  environment: {
    type: "openai_hosted",
    network: { access: "disabled" },
    files: [{ type: "inline", path: "/workspace/amounts.csv", data: "YW1vdW50CjEwCjIwCjMwCg==" }],
  },
  input: "Use Python to sum the amount column in /workspace/amounts.csv. Write a JSON object with the total to /workspace/outputs/summary.json, then read it back to verify it.",
  stream: true,
});
for await (const event of stream) console.log(event);
// Save session.id, wait for agent.session.turn.completed,
// list artifacts, download summary.json -> { "total": 60 }. Delete the session.

      
from openai import OpenAI
client = OpenAI()  # OPENAI_API_KEY stays outside the sandbox
stream = client.beta.agents.sessions.create(
    agent={"model": "gpt-6-astra"},
    environment={
        "type": "openai_hosted",
        "network": {"access": "disabled"},
        "files": [{"type": "inline", "path": "/workspace/amounts.csv",
                   "data": "YW1vdW50CjEwCjIwCjMwCg=="}],
    },
    input=("Use Python to sum the amount column in /workspace/amounts.csv. "
           "Write a JSON object with the total to /workspace/outputs/summary.json, "
           "then read it back to verify it."),
    stream=True,
)
with stream:
    for event in stream:
        print(event.model_dump_json())
