OpenAI-hosted sandboxes — demo

Docs: openai-hosted via shared link. Sandbox workspace is /workspace; outputs go under /workspace/outputs and become immutable artifacts per turn.

1. Local CSV-sum (same logic the sandbox agent runs)

Paste CSV with an amount column, then run. Docs example sums 10+20+30 = 60.

3. Run it live

export OPENAI_API_KEY=sk-...
npm install
node src/createReport.js

Needs an SDK build with the beta Agents API. Keep the key outside the sandbox.
